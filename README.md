# Saki Verso: Lâmina Neon

Projeto privado do canal Saki Verso. Side-scroller 2D inspirado em Rygar, feito em HTML5 Canvas e JavaScript puro, com cinco fases, cinco chefes e um Super Boss final. Joga com teclado ou controle.

Jogar: https://saki-verso.vercel.app

## Arquivos

```
index.html   página do site
style.css    estilo do site
game.js      o jogo (lógica, áudio, fases, chefes) e os sprites embutidos
README.md    este arquivo
```

## Atualizar o site

1. No GitHub, abra o arquivo e clique no lápis (ou use **Add file → Upload files**).
2. Clique em **Commit changes**.
3. A Vercel publica a nova versão sozinha em cerca de um minuto.

## Observação

Este repositório é privado. Todo o código e os sprites (CraftPix, sujeitos à licença deles) ficam só com o dono do projeto.
